# Rockwood Snack Station

Single-file static site (`snack-station-final.html`) deployed to Netlify via GitHub.

## Deployment workflow

Push directly to `main` — no PRs. Netlify auto-deploys on every push to main.

```
git add snack-station-final.html
git commit -m "describe change"
git push -u origin main
```

Do NOT open pull requests unless the user explicitly asks for one.
